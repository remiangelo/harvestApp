# Font Files Required

## Orange Squash Font (Logo)

The Harvest app logo uses the **Orange Squash** font. You need to download this font and place the `.ttf` file in this directory.

### Setup Instructions

1. Download the Orange Squash font from the Google Drive folder:
   https://drive.google.com/drive/folders/1INrc5AACuPFGX5WVxcaVoklBC9J7onht?usp=sharing

2. Rename the font file to `OrangeSquash.ttf`

3. Place it in this directory: `assets/fonts/OrangeSquash.ttf`

4. The app will automatically load the font on startup

### Font Usage

- **Logo font**: Orange Squash (rose red color #EB1E66)
- **Headings**: DM Serif Display (Google Font - already installed)
- **Body text**: DM Sans (Google Font - already installed)

### Fallback

If the Orange Squash font is not available, the app will fall back to the system default font for the logo text.

## Already Included Fonts

- `SpaceMono-Regular.ttf` - Monospace font for code/technical text
- DM Sans (via @expo-google-fonts/dm-sans)
- DM Serif Display (via @expo-google-fonts/dm-serif-display)
