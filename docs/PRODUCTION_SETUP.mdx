## 🔑 OAuth Setup (Optional but Nice)

### Google Login

1. Go to https://console.cloud.google.com
2. Create project "Harvest Dating App"
3. APIs & Services → OAuth consent screen → External
4. Create OAuth client ID
5. Add redirect: `https://jutzlxdboayvmcuqwodn.supabase.co/auth/v1/callback`
6. Copy Client ID & Secret
7. Paste in Supabase → Authentication → Providers → Google

### Facebook Login

1. Go to https://developers.facebook.com
2. Create app → Consumer type
3. Add Facebook Login product
4. Add redirect: `https://jutzlxdboayvmcuqwodn.supabase.co/auth/v1/callback`
5. Copy App ID & Secret
6. Paste in Supabase → Authentication → Providers → Facebook
